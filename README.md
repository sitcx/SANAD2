# سَند (SANAD)

منصة عربية للتوظيف والتدريب على المقابلات للصم وضعاف السمع، مبنية على React وVite وTanStack Start.

## التشغيل في Visual Studio Code

ثبّت Node.js 22.12 أو أحدث، وافتح مجلد المشروع ثم نفّذ:

```bash
npm install
npm run dev
```

افتح http://localhost:3000. الشعار وأيقونة المتصفح مضمّنان محليًا، وأيقونة المتصفح هي الرمز دون الاسم.

## الأوامر

- `npm run build`: تجهيز نسخة الإنتاج في `.output`.
- `npm run preview`: تشغيل نسخة الإنتاج المبنية مسبقًا على http://localhost:3000.
- `npm start`: تشغيل نسخة الإنتاج.
- يمكن تغيير المنفذ بمتغير البيئة PORT.
- `npm test`: تشغيل الاختبارات.

## البيانات والبيئة

هذا نموذج تجريبي؛ الحساب والطلبات والتدريب محفوظة داخل جلسة React فقط. لا توجد قاعدة بيانات أو تسجيل دخول حقيقي أو خدمات ترجمة متصلة. لا يحتاج إلى مفاتيح بيئة، ولا يحتوي على مفاتيح سرية.

جميع الصفحات في `src/routes`، والمكونات في `src/components`، والألوان والخطوط في `src/styles.css`.

خط IBM Plex Sans Arabic يُحمّل من Google Fonts ويحتاج إنترنت؛ يتوفر خط بديل عند عدم الاتصال.
